# Dogg Starz | داگ استارز 🐾⭐

ربات فروش استارز، گیفت و پرمیوم تلگرام.

## ساختار پروژه
- `main.py` — نقطه شروع ربات
- `handlers.py` — تمام منطق منوها، خرید، شارژ کیف پول، پنل ادمین
- `keyboards.py` — دکمه‌های شیشه‌ای (inline) و منوها
- `db.py` — دیتابیس SQLite برای کاربران، سفارش‌ها و درخواست‌های شارژ
- `config.py` — تنظیمات از روی متغیرهای محیطی

## مراحل راه‌اندازی روی Railway

1. این پروژه رو در ریپوی گیت‌هاب `amirm7269/dogg-starz-bot` آپلود کن.
2. توی Railway یه پروژه جدید بساز و از گیت‌هاب همین ریپو رو وصل کن.
3. توی تنظیمات پروژه (Variables) این متغیرها رو اضافه کن:
   - `BOT_TOKEN` = توکن ربات از BotFather
   - `ADMIN_ID` = آیدی عددی تلگرام شما
   - `CARD_NUMBER` = شماره کارت برای واریز (اختیاری)
   - `CARD_HOLDER` = نام صاحب کارت (اختیاری)
4. Railway به‌صورت خودکار از روی `Procfile` ربات رو اجرا می‌کنه.
5. بعد از دیپلوی، به ربات پیام `/start` بده و مطمئن شو منو نشون داده میشه.

## قابلیت‌های فعلی
- منوی اصلی با ۸ دکمه شیشه‌ای دقیقاً مطابق ساختار خواسته‌شده
- خرید استارز، گیفت و پرمیوم از کیف پول داخلی
- افزایش موجودی با کارت‌به‌کارت + ارسال رسید + تایید دستی ادمین
- سیستم زیرمجموعه‌گیری با لینک اختصاصی
- پیگیری وضعیت سفارش‌ها
- پنل ادمین برای تایید/رد شارژ و سفارش (پیام مستقیم با دکمه)

## قابل توسعه در آینده
- اتصال درگاه پرداخت آنلاین (زرین‌پال و امثالش)
- پنل مدیریت کامل‌تر (لیست کاربران، آمار فروش)
- پاداش خودکار برای زیرمجموعه‌گیری
